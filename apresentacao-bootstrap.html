O que é Bootstrap?

Bootstrap é o framework front-end mais popular do mundo para construção de sites responsivos e mobile-first. Criado originalmente pelo Twitter em 2011, é um conjunto de ferramentas que inclui HTML, CSS e JavaScript.

📚 Principais Características

  • Sistema de Grid Responsivo: Organize o layout de forma flexível e adaptável
  • Componentes Pré-construídos: Botões, formulários, navegação, cards e muito mais
  • Classes Utilitárias: Estilização rápida sem escrever CSS customizado
  • Compatibilidade: Funciona em todos os navegadores modernos
  • Documentação Completa: Guias detalhados e exemplos práticos
  • Open Source: Gratuito e mantido por uma grande comunidade

Como Instalar o Bootstrap

🔗 Método 1: Via CDN (Mais Rápido)

Adicione estas linhas no <head> do seu HTML:

<!-- CSS do Bootstrap -->
<link href="https://cdn.jsdelivr.net/npm/bootstrap@5.3.2/dist/css/bootstrap.min.css" 
      rel="stylesheet">

<!-- JavaScript do Bootstrap (antes do </body>) -->
<script src="https://cdn.jsdelivr.net/npm/bootstrap@5.3.2/dist/js/bootstrap.bundle.min.js">
</script>

📦 Método 2: Download

  1. Acesse getbootstrap.com
  2. Baixe a versão compilada
  3. Extraia os arquivos na pasta do seu projeto
  4. Referencie os arquivos CSS e JS localmente

⚠️ Atenção!

Sempre inclua o CSS no <head> e o JavaScript antes do fechamento de </body> para melhor desempenho!

Template HTML Básico com Bootstrap

Este é um template completo para iniciar qualquer projeto Bootstrap:

<!DOCTYPE html>
<html lang="pt-BR">
<head>
    <meta charset="UTF-8">
    <meta name="viewport" content="width=device-width, initial-scale=1.0">
    <title>Meu Site com Bootstrap</title>
    
    <!-- CSS do Bootstrap -->
    <link href="https://cdn.jsdelivr.net/npm/bootstrap@5.3.2/dist/css/bootstrap.min.css" 
          rel="stylesheet">
</head>
<body>
    
    <h1 class="text-center">Olá, Bootstrap!</h1>
    
    <!-- JavaScript do Bootstrap -->
    <script src="https://cdn.jsdelivr.net/npm/bootstrap@5.3.2/dist/js/bootstrap.bundle.min.js">
    </script>
</body>
</html>

✅ Pronto para usar!

Copie este template e comece a adicionar componentes Bootstrap. A tag viewport é essencial para responsividade!

Sistema de Grid - Fundamentos

O Grid System é a base do Bootstrap. Ele usa um sistema de 12 colunas flexíveis que se adaptam automaticamente ao tamanho da tela.

🏗️ Estrutura Básica

Componentes do Grid:

  • container - Envolve todo o conteúdo
  • row - Agrupa colunas horizontalmente
  • col - Define as colunas

Breakpoints:

  • sm ≥ 576px
  • md ≥ 768px
  • lg ≥ 992px
  • xl ≥ 1200px

Sistema de Grid - Exemplos

📝 Exemplo 1: Três Colunas Iguais

<div class="container">
    <div class="row">
        <div class="col">Coluna 1</div>
        <div class="col">Coluna 2</div>
        <div class="col">Coluna 3</div>
    </div>
</div>

📝 Exemplo 2: Colunas com Tamanhos Específicos

<div class="container">
    <div class="row">
        <div class="col-8">Conteúdo Principal (8 colunas)</div>
        <div class="col-4">Sidebar (4 colunas)</div>
    </div>
</div>

📝 Exemplo 3: Responsivo (Diferentes Telas)

<div class="container">
    <div class="row">
        <div class="col-12 col-md-6 col-lg-4">Card 1</div>
        <div class="col-12 col-md-6 col-lg-4">Card 2</div>
        <div class="col-12 col-md-6 col-lg-4">Card 3</div>
    </div>
</div>

💡 Mobile: 1 coluna | Tablet: 2 colunas | Desktop: 3 colunas

Componentes: Botões

Bootstrap oferece diversos estilos de botões prontos para uso:

🎨 Cores dos Botões

<button class="btn btn-primary">Primary</button>
<button class="btn btn-secondary">Secondary</button>

<button class="btn btn-danger">Danger</button>

<button class="btn btn-primary">Normal</button>
<button class="btn btn-primary btn-sm">Pequeno</button>

<!-- Botão com contorno -->
<button class="btn btn-outline-primary">Outline</button>

<!-- Botão de bloco (largura total) -->
<button class="btn btn-primary w-100">Botão Bloco</button>

<!-- Botão desabilitado -->
<button class="btn btn-primary" disabled>Desabilitado</button>

Componentes: Cards

Cards são containers flexíveis e extensíveis para exibir conteúdo:

🃏 Card Básico

<div class="card" style="width: 18rem;">
    <img src="imagem.jpg" class="card-img-top" alt="...">
    <div class="card-body">
        <h5 class="card-title">Título do Card</h5>
        <p class="card-text">Descrição do conteúdo do card.</p>
        <a href="#" class="btn btn-primary">Ver mais</a>
    </div>
</div>

🎨 Card com Header e Footer

<div class="card">
    <div class="card-header">
        Cabeçalho
    </div>
    <div class="card-body">
        <h5 class="card-title">Título</h5>
        <p class="card-text">Conteúdo do card.</p>
    </div>
    <div class="card-footer text-muted">
        Rodapé
    </div>
</div>

💡 Dica Profissional

Combine cards com o sistema de grid para criar layouts de galeria responsivos!

Componentes: Navbar (Barra de Navegação)

Crie menus de navegação profissionais e responsivos:

<nav class="navbar navbar-expand-lg navbar-dark bg-dark">
    <div class="container-fluid">
        <a class="navbar-brand" href="#">Meu Site</a>
        
        <button class="navbar-toggler" type="button" 
                data-bs-toggle="collapse" 
                data-bs-target="#navbarNav">
            <span class="navbar-toggler-icon"></span>
        </button>
        
        <div class="collapse navbar-collapse" id="navbarNav">
            <ul class="navbar-nav">
                <li class="nav-item">
                    <a class="nav-link active" href="#">Início</a>
                </li>
                <li class="nav-item">
                    <a class="nav-link" href="#">Sobre</a>
                </li>
                <li class="nav-item">
                    <a class="nav-link" href="#">Contato</a>
                </li>
            </ul>
        </div>
    </div>
</nav>

📱 Responsividade Automática

O navbar se transforma em menu hambúrguer em telas pequenas automaticamente!

Classes Utilitárias

Bootstrap oferece centenas de classes para estilização rápida:

🎨 Cores

<!-- Cor do texto -->
<p class="text-primary">Texto azul</p>
<p class="text-success">Texto verde</p>
<p class="text-danger">Texto vermelho</p>

<!-- Cor de fundo -->
<div class="bg-primary text-white">Fundo azul</div>
<div class="bg-success text-white">Fundo verde</div>

📏 Espaçamento (Margin e Padding)

<!-- m = margin, p = padding -->
<!-- t=top, b=bottom, s=start, e=end, x=horizontal, y=vertical -->

<div class="mt-3">Margin top 3</div>
<div class="p-4">Padding 4</div>
<div class="mx-auto">Margem horizontal automática (centraliza)</div>
<div class="my-5">Margem vertical 5</div>

📝 Texto

<p class="text-center">Centralizado</p>
<p class="text-start">Início</p>
<p class="text-end">Fim</p>
<p class="fw-bold">Negrito</p>
<p class="fst-italic">Itálico</p>
<p class="text-uppercase">maiúsculas</p>

Classes Utilitárias: Display e Flexbox

👁️ Display

<div class="d-none">Escondido</div>
<div class="d-block">Bloco</div>
<div class="d-inline">Inline</div>
<div class="d-flex">Flexbox</div>

<!-- Container Flexbox -->

    <div>Item 1</div>
    <div>Item 2</div>
</div>

<!-- Alinhamento -->
<div class="d-flex justify-content-between">...</div>
<div class="d-flex align-items-center">...</div>
<div class="d-flex flex-column">...</div>

📐 Dimensões

<div class="w-25">Largura 25%</div>
<div class="w-50">Largura 50%</div>
<div class="w-100">Largura 100%</div>
<div class="h-50">Altura 50%</div>
