2.2 — Digitação com teclas especiais no Bloco de Notas

Restaure o Bloco de Notas na barra de tarefas. Digite exatamente as linhas abaixo, prestando atenção às maiúsculas, acentos e símbolos:

⚠️ Para os acentos: pressione primeiro a tecla do acento (´ ou ` ou ~) e depois a vogal desejada.
⚡

2.3 — Atalhos essenciais do teclado

No Bloco de Notas, execute os atalhos abaixo na ordem indicada:

Digite um pequeno texto (pode ser o seu nome e a data de hoje).
Pressione Ctrl + A para selecionar tudo.
Pressione Ctrl + C para copiar.
Clique no final do texto e pressione Ctrl + V duas vezes para colar.
Selecione a última linha com o mouse, pressione Ctrl + X para recortar.
Posicione o cursor no início do texto e pressione Ctrl + V para colar no novo local.
Salve o arquivo com Ctrl + S, com o nome atalhos_seuNome.txt, na área de trabalho.

Explorador de ArquivosPastas, arquivos, compactação e lixeira

📁

3.1 — Criando pastas e arquivo de texto

Abra o Explorador de Arquivos com Win + E e realize os passos a seguir na Área de Trabalho:

Crie uma pasta chamada Meus_Arquivos (clique direito → Novo → Pasta).
Dentro de Meus_Arquivos, crie três subpastas: Textos, Imagens e Projetos.
Dentro de Textos, crie um arquivo de texto chamado resumo.txt.
Abra resumo.txt e digite: "Este é meu primeiro arquivo criado na prática."
Salve e feche o arquivo.
🗃️

3.2 — Operações com arquivos: copiar, renomear, excluir e restaurar

Copie o arquivo resumo.txt da pasta Textos para a pasta Projetos (Ctrl+C → abrir Projetos → Ctrl+V).
Renomeie o arquivo copiado para resumo_projetos.txt (clique direito → Renomear).
Exclua o arquivo original resumo.txt da pasta Textos (selecione → tecla Delete).
Abra a Lixeira na Área de Trabalho e verifique se o arquivo está lá.
Restaure o arquivo: clique direito nele → Restaurar. Confira se voltou à pasta Textos.

Questão 2. Quando você exclui um arquivo com a tecla Delete, ele é permanentemente apagado?

🗜️

3.3 — Compactando e extraindo arquivos (.zip)

📦 Compactar arquivos é como colocar várias coisas em uma caixa menor — os arquivos ficam agrupados e ocupam menos espaço.
Clique com o botão direito na pasta Projetos.
Selecione "Enviar para" → "Pasta compactada (zipada)".
Renomeie o arquivo gerado para backup_projetos.zip.
Clique com o botão direito no .zip → "Extrair tudo" → Escolha um local → Extrair.
