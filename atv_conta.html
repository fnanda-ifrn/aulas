Atividade Prática de Revisão
Sistema Bancário com POO

Objetivo

Desenvolver um sistema bancário simplificado aplicando os conceitos fundamentais de POO visto até agora na disciplina.

Descrição

Você foi contratado(a) para desenvolver o módulo principal de um sistema bancário que deve gerenciar clientes, contas bancárias e operações financeiras básicas. O sistema deve ser desenvolvido seguindo boas práticas de POO e organização de código.

Requisitos Técnicos

1. Estrutura do Projeto

Organize seu projeto na seguinte estrutura de pacotes e módulos:

banco/
├── __init__.py
├── clientes.py # Módulo para a classe Cliente
├── contas.py # Módulo para classes de Conta
└── main.py # Programa principal

2. Implementação das Classes

Classe Cliente

Desenvolva no módulo clientes.py uma classe para representar clientes do banco com:

  • Atributos básicos: nome, CPF e data de nascimento
  • Método para representação textual do cliente (vai exibir informações do cliente textualmente)
  • Encapsulamento adequado dos atributos

Classe Conta (Superclasse)

Implemente no módulo contas.py uma classe base para contas bancárias com:

  • Atributos: número da conta, cliente associado (objeto Cliente), saldo e histórico de transações (lista de strings)
  • Métodos básicos: depositar, sacar e exibir_extrato
  • Encapsulamento adequado (proteja-os com valores permitidos)
  • Armazenamento das transações em uma lista

Classes Especializadas

Derive da classe Conta as seguintes especializações:

  • ContaCorrente: Com limite de cheque especial e regras específicas para saque levando em conta o cheque especial
  • ContaPoupanca: Com taxa de rendimento e cada saque desconta 0.2% do saldo da conta
Dica: Utilize herança e polimorfismo para implementar comportamentos específicos em cada tipo de conta.

Passo a Passo

Implementação das Classes

  1. Crie a classe Cliente com todos os atributos e métodos necessários
  2. Implemente a classe base Conta com os métodos básicos de operação bancária
  3. Desenvolva as classes especializadas ContaCorrente e ContaPoupanca
  4. Garanta o uso adequado de encapsulamento em todas as classes

Programa Principal

  1. Desenvolva um menu interativo no módulo principal (main.py)
  2. Permita cadastrar clientes e contas
  3. Implemente as operações bancárias através do menu
  4. Exiba extratos completos das contas

Entrega: Através de atividade no GSA da turma.

Formato: Arquivo ZIP contendo todo o projeto. Titulo do arquivo ZIP é seu nome completo.

Dica: Teste cada classe separadamente antes de integrar ao sistema!
