Introdução

O que são coleções?

Coleções são estruturas que guardam vários valores em uma única variável. Pense em uma caixa onde você coloca vários itens — é isso que uma coleção faz no Python.

Por que usar? Organizam os dados, facilitam operações repetitivas e deixam o código bem menor.
Hoje veremos quatro tipos: listas, tuplas, dicionários e conjuntos.
Visão geral

As quatro coleções do Python

Duas perguntas para escolher

  • Os dados vão mudar durante o programa?
  • Como vou buscar um item depois: pela posição ou por um nome/código?
Atenção à sintaxe: dicionário e conjunto usam as mesmas chaves { }. A diferença é o conteúdo: {"nome": "Ana"} é dicionário, {"Ana", "Bruno"} é conjunto.
Listas

Criando uma lista

frutas = ["maçã", "banana", "laranja", "uva"] numeros = [1, 2, 3, 4, 5] misturado = [10, "texto", True, 3.14] vazia = [] # lista vazia, para preencher depois
Os itens ficam entre colchetes [ ] e são separados por vírgula.

Características das listas

  • São ordenadas: mantêm a ordem em que você colocou os itens.
  • São mutáveis: dá para alterar, adicionar e remover.
  • Permitem itens repetidos.
  • Podem misturar tipos, mas o normal é guardar itens do mesmo tipo.
Listas

Cada item tem uma posição

A posição de um item se chama índice. E atenção: a contagem começa no zero.

Listas

Acessando e alterando

frutas = ["maçã", "banana", "laranja", "uva"] # acessando print(frutas[0]) # maçã print(frutas[2]) # laranja # alterando um item frutas[1] = "morango" print(frutas) # ['maçã', 'morango', 'laranja', 'uva'] # quantos itens tem? print(len(frutas)) # 4 # o item está na lista? if "uva" in frutas: print("Tem uva!")
len( )

Conta quantos itens a lista tem. Como a contagem de índices começa no zero, o último índice é sempre len(lista) - 1.

operador in

Responde True ou False para "esse valor está na lista?". Serve também para tuplas, dicionários e conjuntos.

Como a lista é mutável, escrever frutas[1] = "morango" troca o item que já estava lá.
Listas

Adicionando e removendo itens

frutas.append("abacaxi") # adiciona no final frutas.insert(1, "kiwi") # insere na posição 1
frutas.remove("laranja") # remove pelo valor frutas.pop(2) # remove pelo índice

Listas

Percorrendo uma lista

frutas = ["maçã", "banana", "uva"] for f in frutas: print(f) # maçã # banana # uva
O for pega um item por vez, do primeiro ao último. A variável f muda de valor a cada volta do laço.

Tuplas

Parecida com a lista, mas travada

coordenadas = (10, 20) cores = ("vermelho", "verde", "azul") # acessar é igual ao da lista print(cores[1]) # verde print(len(cores)) # 3 # alterar NÃO funciona cores[1] = "amarelo" # TypeError
Curiosidade: tupla com um único elemento precisa da vírgula: tupla = (1,). Sem ela, (1) é só o número 1.
Tuplas

Quando usar tupla?

Dados fixos

Valores que não devem mudar: as cores oficiais de um site, os dias da semana, as coordenadas de um ponto.

DIAS = ("seg", "ter", "qua")
Segurança

Ninguém consegue alterar aquele dado por engano em outra parte do programa. O próprio Python impede.

ponto = (10, 20) ponto[0] = 99 # erro
Desempenho

Tuplas são mais leves e mais rápidas que listas. Em coleções grandes que só serão lidas, isso faz diferença.

cores = ("azul", "verde")
Resumindo: se o conteúdo vai mudar durante o programa, use lista. Se é uma informação fixa, use tupla.
Dicionários

Cada valor tem um nome: a chave

aluno = { "nome": "João Silva", "idade": 16, "turma": "2ºA", "notas": [7.5, 8.0, 6.5] } print(aluno["nome"]) # João Silva
Na lista você busca pela posição (alunos[0]). No dicionário você busca pelo nome da informação (aluno["nome"]) — bem mais claro de ler.
Dicionários

Acessando, adicionando e alterando

aluno = {"nome": "João", "idade": 16} # acesso direto print(aluno["nome"]) # João # acesso seguro print(aluno.get("idade")) # 16 print(aluno.get("turma")) # None print(aluno.get("turma", "2ºA")) # 2ºA # alterar um valor aluno["idade"] = 17 # adicionar uma chave nova aluno["escola"] = "IFRN"
FormaQuando usar
aluno["nome"]quando você tem certeza de que a chave existe
aluno.get("nome")quando a chave pode não existir
Cuidado: aluno["turma"] gera KeyError se a chave não existir. Já .get() devolve None (ou o valor padrão que você indicar) sem quebrar o programa.
A mesma linha aluno["escola"] = "IFRN" altera se a chave já existe e cria se ainda não existe.
Dicionários

Removendo e percorrendo

Removendo

aluno.pop("turma") # remove e devolve o valor del aluno["idade"] # remove sem devolver aluno.clear() # esvazia o dicionário # a chave existe? if "notas" in aluno: print("Tem informações de notas")

Percorrendo os pares

for chave, valor in aluno.items(): print(f"{chave}: {valor}")

Tempo: 15 minutos

Crie um dicionário representando um celular, com as chaves: marca, modelo, ano, preço e acessórios (uma lista com pelo menos 3 itens). Depois:

  1. Adicione uma nova chave "cor".
  2. Remova a chave "preço".
  3. Verifique se "bateria" está na lista de acessórios.
  4. Mostre todas as chaves e valores usando .items().

Ponto de partida

celular = { "marca": "XPTO", "modelo": "Z10", "ano": 2024, "preço": 1200, "acessórios": ["capa", "fone", "carregador"] }
A chave "acessórios" guarda uma lista dentro do dicionário. Para verificar um acessório: "bateria" in celular["acessórios"].
Conjuntos

Itens únicos, sem repetição

numeros = {1, 2, 3, 4, 5} # repetidos somem sozinhos letras = set(["a", "b", "c", "a"]) print(letras) # {'a', 'b', 'c'} # adicionando numeros.add(6) numeros.update([7, 8, 9]) # removendo numeros.remove(3) # erro se não existir numeros.discard(10) # não dá erro
Conjuntos

Operações entre conjuntos

A = {1, 2, 3} B = {3, 4, 5} print(A | B) # ou A.union(B) print(A & B) # ou A.intersection(B) print(A - B) # ou A.difference(B)

Na prática, isso responde

  • Quem está nas duas turmas? → interseção
  • Quais alunos existem no total? → união
  • Quem ainda não entregou o trabalho? → diferença

Fechando

O que aprendemos hoje

  • Listas [ ] — coleções ordenadas e que podem ser alteradas.
  • Tuplas ( ) — ordenadas, mas imutáveis.
  • Dicionários {chave: valor} — cada valor tem um nome.
  • Conjuntos { } — itens únicos, sem ordem.
  • Todas podem ser percorridas com for e testadas com in.
Próximos passos: pratique criando pequenos programas com cada tipo de coleção. É a prática que fixa o conteúdo.
