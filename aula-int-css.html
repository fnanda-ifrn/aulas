Introdução ao CSS

Cascading Style Sheets

Disciplina: Autoria Web

Profa: Fernanda Lígia

O que é CSS?

CSS (Cascading Style Sheets) é uma linguagem de estilo utilizada para definir a apresentação visual de documentos HTML.

Por que usar CSS?

  • Separação de conteúdo e apresentação: HTML cuida da estrutura, CSS cuida do visual
  • Reutilização de código: Um único arquivo CSS pode estilizar múltiplas páginas
  • Facilidade de manutenção: Alterações visuais centralizadas
  • Melhor desempenho: Reduz repetição de código
  • Design responsivo: Adapta o layout para diferentes dispositivos
Sem CSS, todas as páginas web teriam apenas a aparência padrão do navegador!

Visão Geral do CSS

Conceitos Fundamentais

CSS funciona através de regras que definem como os elementos HTML devem ser exibidos.

Estrutura Básica:

seletor {
    propriedade: valor;
    propriedade: valor;
}

Exemplo Prático:

p {
    color: blue;        /* propriedade: color | valor: blue */
    font-size: 16px;    /* propriedade: font-size | valor: 16px */
}

Resultado: Todos os parágrafos <p> terão texto azul com tamanho de 16 pixels.

Declaração CSS

Uma declaração CSS é composta por uma propriedade e um valor, separados por dois pontos e finalizados com ponto e vírgula.

Anatomia de uma Declaração:

propriedade: valor;

Exemplos de Declarações:

color: red;                    /* propriedade: color | valor: red */
font-size: 18px;               /* propriedade: font-size | valor: 18px */
background-color: yellow;      /* propriedade: background-color | valor: yellow */
margin: 10px;                 /* propriedade: margin | valor: 10px */
border: 1px solid black;     /* propriedade: border | valor: 1px solid black */
O ponto e vírgula (;) ao final de cada declaração é obrigatório quando há múltiplas declarações. É uma boa prática sempre utilizá-lo.

Regras CSS

Uma regra CSS é formada por um seletor seguido de um bloco de declarações entre chaves.

Estrutura Completa:

seletor {
    declaração1;
    declaração2;
    declaração3;
}

Exemplo Completo:

h1 {                            /* SELETOR */
    color: #333;                /* declaração */
    font-size: 32px;            /* declaração */
    text-align: center;         /* declaração */
    margin-bottom: 20px;        /* declaração */
}

Neste exemplo:

  • h1 é o seletor (seleciona todos os elementos h1)
  • O bloco entre { } contém as declarações
  • Cada linha é uma declaração com propriedade e valor

CSS Inline (Como Atributo)

CSS inline é aplicado diretamente no elemento HTML através do atributo style.

Sintaxe:

<elemento style="propriedade: valor; propriedade: valor;">

Exemplos:

<h1 style="color: blue; font-size: 28px;">Título Azul</h1>

<p style="background-color: yellow; padding: 10px;">
    Parágrafo com fundo amarelo
</p>

<div style="border: 2px solid red; margin: 20px;">
    Div com borda vermelha
</div>
CSS inline tem a maior prioridade (especificidade) de todas as formas de CSS!

CSS Inline - Prós e Contras

✅ Vantagens

  • Rápido para testes
  • Útil para estilos únicos
  • Maior especificidade
  • Não requer arquivo externo

❌ Desvantagens

  • Dificulta manutenção
  • Não reutilizável
  • Mistura HTML e CSS
  • Código repetitivo
  • Dificulta responsividade
Use CSS inline apenas para casos muito específicos ou testes rápidos. Não é recomendado para projetos reais.

CSS Interno (No Documento HTML)

CSS interno é definido dentro da tag <style> na seção <head> do documento HTML.

Estrutura:

<!DOCTYPE html>
<html>
<head>
    <title>Minha Página</title>
    <style>
        body {
            background-color: #f0f0f0;
            font-family: Arial, sans-serif;
        }
        
        h1 {
            color: navy;
            text-align: center;
        }
        
        p {
            color: #333;
            line-height: 1.6;
        }
    </style>
</head>
<body>
    <h1>Título</h1>
    <p>Parágrafo</p>
</body>
</html>

CSS Interno - Prós e Contras

✅ Vantagens

  • Estilos centralizados na página
  • Não requer arquivo externo
  • Útil para páginas únicas
  • Boa para protótipos
  • Facilita testes

❌ Desvantagens

  • Não reutilizável entre páginas
  • Aumenta tamanho do HTML
  • Dificulta manutenção em sites grandes
  • Não aproveita cache do navegador
  • Código duplicado em múltiplas páginas
CSS interno é ideal para páginas simples ou quando você tem estilos específicos para uma única página.

CSS Externo (Arquivo Separado)

CSS externo é definido em um arquivo separado com extensão .css e vinculado ao HTML através da tag <link>.

Arquivo: estilos.css

/* Arquivo: estilos.css */
body {
    background-color: #f0f0f0;
    font-family: Arial, sans-serif;
    margin: 0;
    padding: 0;
}

h1 {
    color: navy;
    text-align: center;
    padding: 20px;
}

p {
    color: #333;
    line-height: 1.6;
    margin: 15px;
}

Arquivo: index.html

<!DOCTYPE html>
<html>
<head>
    <title>Minha Página</title>
    <link rel="stylesheet" href="estilos.css">
</head>
<body>
    <h1>Título</h1>
    <p>Parágrafo</p>
</body>
</html>

CSS Externo - Prós e Contras

✅ Vantagens (MAIS RECOMENDADO!)

  • Separação completa de conteúdo e estilo
  • Reutilizável em múltiplas páginas
  • Facilita manutenção
  • Aproveita cache do navegador
  • Organização do código
  • Trabalho em equipe facilitado
  • HTML mais limpo e leve

❌ Desvantagens

  • Requer arquivo adicional
  • Requisição HTTP extra
  • Pode haver delay no carregamento
CSS externo é a forma MAIS RECOMENDADA para projetos reais! É o padrão da indústria.

Comparação dos Três Métodos

Característica Inline Interno Externo
Localização No atributo style Tag <style> no <head> Arquivo .css separado
Reutilização ❌ Não ⚠️ Apenas na página ✅ Múltiplas páginas
Manutenção ❌ Difícil ⚠️ Moderada ✅ Fácil
Performance ⚠️ Média ⚠️ Média ✅ Melhor (cache)
Especificidade Mais alta Média Mais baixa
Uso Recomendado Testes rápidos Páginas únicas Projetos reais ✅

Ordem de Precedência (Cascata)

Quando múltiplos estilos são aplicados ao mesmo elemento, o CSS segue uma ordem de prioridade:

Ordem de Prioridade (do maior para o menor):

  1. !important - Força máxima prioridade
  2. CSS Inline - style no elemento
  3. CSS Interno/Externo - Por especificidade do seletor
  4. Estilo padrão do navegador

Exemplo de Conflito:

<!-- CSS Externo -->
p { color: blue; }

<!-- CSS Interno -->
<style>
    p { color: green; }
</style>

<!-- CSS Inline -->
<p style="color: red;">Este texto será vermelho!</p>
O CSS inline vence! Evite usar !important - isso dificulta muito a manutenção do código.

Seletores CSS

Os seletores são padrões usados para selecionar e estilizar elementos HTML.

Por que são importantes?

  • Definem quais elementos receberão os estilos
  • Permitem aplicar estilos de forma específica ou ampla
  • Organizam e estruturam o CSS
  • Aumentam a reutilização de código

Principais Tipos de Seletores:

  1. Seletores de Elemento - Selecionam por tag HTML
  2. Seletores de Classe - Selecionam por atributo class
  3. Seletores de ID - Selecionam por atributo id
  4. Pseudoclasses - Selecionam estados especiais
Cada tipo de seletor tem seu uso específico. Vamos explorar cada um deles em detalhes!

Seletores de Elemento (Tag)

Selecionam todos os elementos de um determinado tipo (tag HTML).

Sintaxe:

nome-da-tag {
    propriedade: valor;
}

Exemplos:

/* Seleciona todos os parágrafos */
p {
    color: blue;
    font-size: 16px;
}

/* Seleciona todos os títulos h1 */
h1 {
    color: navy;
    text-align: center;
}

/* Seleciona todas as imagens */
img {
    width: 100%;
    border-radius: 5px;
}

/* Seleciona todos os links */
a {
    color: #007bff;
    text-decoration: none;
}
Seletores de elemento aplicam estilos a TODOS os elementos daquele tipo na página!

Seletores de Classe

Selecionam elementos que possuem um atributo class específico. Classes são reutilizáveis e podem ser aplicadas a múltiplos elementos.

Sintaxe:

.nome-da-classe {
    propriedade: valor;
}

No HTML:

<p class="destaque">Texto em destaque</p>
<div class="destaque">Div também em destaque</div>

No CSS:

/* Seleciona todos com class="destaque" */
.destaque {
    background-color: yellow;
    font-weight: bold;
    padding: 10px;
}

.botao-primario {
    background-color: #007bff;
    color: white;
    padding: 10px 20px;
    border-radius: 5px;
}

.texto-centralizado {
    text-align: center;
}
Classes são a forma MAIS RECOMENDADA para estilizar elementos! Use nomes descritivos e semânticos.

Múltiplas Classes

Um elemento HTML pode ter múltiplas classes separadas por espaço.

HTML:

<button class="botao botao-grande botao-azul">
    Clique Aqui
</button>

CSS:

/* Estilo base do botão */
.botao {
    padding: 10px 20px;
    border: none;
    border-radius: 5px;
    cursor: pointer;
}

/* Modificador de tamanho */
.botao-grande {
    font-size: 18px;
    padding: 15px 30px;
}

/* Modificador de cor */
.botao-azul {
    background-color: #007bff;
    color: white;
}

Vantagens:

  • Reutilização de estilos
  • Código mais organizado e modular
  • Facilita manutenção
  • Permite combinações flexíveis

Seletores de ID

Selecionam o elemento que possui um atributo id específico. IDs devem ser únicos na página.

Sintaxe:

#nome-do-id {
    propriedade: valor;
}

No HTML:

<header id="cabecalho-principal">
    <h1>Meu Site</h1>
</header>

No CSS:

/* Seleciona o elemento com id="cabecalho-principal" */
#cabecalho-principal {
    background-color: #333;
    color: white;
    padding: 20px;
}

#rodape {
    background-color: #f0f0f0;
    text-align: center;
    padding: 15px;
}
IMPORTANTE: Cada ID deve ser único na página! Para estilização, prefira usar classes. Use IDs principalmente para JavaScript ou âncoras.

Diferenças: Classe vs ID

Característica Classe (.classe) ID (#id)
Símbolo . (ponto) # (hashtag)
Unicidade Reutilizável múltiplas vezes Único na página
Especificidade Menor (10 pontos) Maior (100 pontos)
Uso por elemento Múltiplas classes por elemento Apenas um ID por elemento
Uso recomendado Estilização CSS ✅ JavaScript, âncoras

Exemplo Comparativo:

<!-- RECOMENDADO: Usar classes -->
<div class="card card-destaque">Conteúdo</div>
<div class="card">Outro conteúdo</div>

<!-- ID: Usar para identificação única -->
<header id="topo">Cabeçalho</header>
Para CSS, use classes! IDs são melhores para JavaScript e navegação por âncoras.

Pseudoclasses

Pseudoclasses selecionam elementos em estados específicos ou posições especiais.

Sintaxe:

seletor:pseudoclasse {
    propriedade: valor;
}

Pseudoclasses de Interação:

/* Quando o mouse passa sobre o link */
a:hover {
    color: red;
    text-decoration: underline;
}

/* Quando o elemento está com foco */
input:focus {
    border-color: blue;
    outline: 2px solid lightblue;
}

/* Link já visitado */
a:visited {
    color: purple;
}

/* Enquanto o elemento está sendo clicado */
button:active {
    transform: scale(0.95);
}

Pseudoclasses Estruturais

Selecionam elementos por sua posição:

/* Primeiro filho */
li:first-child {
    font-weight: bold;
}

/* Último filho */
li:last-child {
    border-bottom: none;
}

/* Enésimo filho (linhas pares) */
tr:nth-child(even) {
    background-color: #f2f2f2;
}

/* Enésimo filho (linhas ímpares) */
tr:nth-child(odd) {
    background-color: white;
}

/* Terceiro elemento */
li:nth-child(3) {
    color: red;
}

Outras Pseudoclasses Úteis:

/* Campo desabilitado */
input:disabled {
    opacity: 0.5;
}

/* Campo obrigatório */
input:required {
    border-left: 3px solid orange;
}

Exemplo Prático com Pseudoclasses

HTML:

<nav>
    <ul>
        <li><a href="#home">Home</a></li>
        <li><a href="#sobre">Sobre</a></li>
        <li><a href="#contato">Contato</a></li>
    </ul>
</nav>

CSS:

/* Estilo padrão dos links */
nav a {
    color: #333;
    text-decoration: none;
    padding: 10px 15px;
    display: inline-block;
}

/* Efeito hover - mouse sobre o link */
nav a:hover {
    background-color: #007bff;
    color: white;
    border-radius: 5px;
    transition: all 0.3s;
}

/* Link ativo/sendo clicado */
nav a:active {
    background-color: #0056b3;
}

/* Primeiro item do menu */
nav li:first-child a {
    font-weight: bold;
}

Propriedades e Valores

Propriedades Mais Comuns:

Propriedade O que faz Exemplo
color Cor do texto color: red;
background-color Cor de fundo background-color: #f0f0f0;
font-size Tamanho da fonte font-size: 16px;
margin Espaçamento externo margin: 10px;
padding Espaçamento interno padding: 15px;
border Borda do elemento border: 1px solid black;

Boas Práticas CSS

✅ Sempre Faça:

  • Use CSS externo em arquivos .css separados
  • Prefira classes para estilização
  • Use seletores de elemento para estilos globais
  • Organize o código com comentários
  • Use nomes de classes descritivos e semânticos
  • Mantenha a consistência na nomenclatura
  • Agrupe propriedades relacionadas
  • Use pseudoclasses para interatividade
  • Indente o código corretamente

❌ Evite:

  • CSS inline em projetos reais
  • Uso excessivo de !important
  • IDs para estilização (prefira classes)
  • Seletores muito específicos e complexos
  • Código duplicado

Exercício Prático 1

Criando uma Página com Seletores

Crie uma página HTML e um arquivo CSS externo com:

HTML deve conter:

  • Um título principal (h1)
  • Três parágrafos, sendo um com class="destaque"
  • Uma div com id="container"
  • Uma lista não ordenada (ul) com 4 itens (li)

CSS deve aplicar:

  • Estilo para todos os parágrafos (seletor de elemento)
  • Estilo especial para o parágrafo com class="destaque"
  • Estilo para a div com id="container"
  • Efeito hover nos itens da lista
  • Estilo diferenciado para o primeiro item da lista (:first-child)
Experimente diferentes cores, tamanhos e espaçamentos. Use o que aprendeu sobre seletores!

Exercício Prático 2

Praticando os Três Métodos de CSS

Parte 1: Crie um parágrafo usando CSS inline com:

  • Cor de texto vermelha
  • Tamanho de fonte 20px
  • Fundo amarelo

Parte 2: Na mesma página, adicione CSS interno com:

  • Estilo para todos os h2 (cor azul, centralizado)
  • Uma classe .caixa (borda, padding, background)

Parte 3: Observe qual estilo prevalece quando:

  • Você aplica CSS inline e classe ao mesmo elemento
  • Você define a mesma propriedade de formas diferentes

Reflexão: Qual método é mais prático? Por quê?

Exercício Prático 3

Menu de Navegação com Pseudoclasses

Crie um menu de navegação horizontal com:

HTML:

  • Uma tag <nav> contendo uma lista <ul>
  • 4 itens de menu (<li>) com links (<a>)

CSS (arquivo externo):

  • Remova os marcadores da lista
  • Deixe os itens alinhados horizontalmente (display: inline-block)
  • Estilize os links (cor, sem sublinhado, padding)
  • Use :hover para mudar cor de fundo ao passar o mouse
  • Use :active para efeito ao clicar
  • Use :first-child para destacar o primeiro item
Adicione transições suaves: transition: all 0.3s; para um efeito mais profissional!
