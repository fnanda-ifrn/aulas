O que são Formulários HTML?

Formulários são elementos fundamentais da web que permitem aos usuários enviar dados para um servidor.

Principais Usos:

  • Formulários de contato
  • Cadastro de usuários
  • Login em sistemas
  • Pesquisas e enquetes
  • Comentários em blogs
  • Compras online
Importante: Formulários HTML coletam dados do usuário, mas o processamento desses dados é feito no servidor (backend) usando linguagens como PHP, Python, JavaScript (Node.js), etc.

Estrutura Básica de um Formulário

A tag <form>

Todo formulário HTML começa com a tag <form> que define onde o formulário começa e termina.

<form action="processar.php" method="POST">
    <!-- Campos do formulário aqui -->
</form>

Atributos Principais:

  • action: Define para onde os dados serão enviados
  • method: Define como os dados serão enviados (GET ou POST)
GET vs POST:
• GET: Dados visíveis na URL, limite de tamanho, usado para buscas
• POST: Dados ocultos, sem limite de tamanho, usado para envio de informações sensíveis

A Tag <input>

O elemento mais versátil dos formulários. Pode assumir diferentes tipos através do atributo type.

Estrutura Básica:

<input type="text" name="nome" id="nome" placeholder="Digite seu nome">

Atributos Importantes:

  • type: Define o tipo de entrada
  • name: Nome do campo (usado no servidor)
  • id: Identificador único
  • placeholder: Texto de dica
  • value: Valor padrão
  • required: Campo obrigatório

Tipos de Input - Texto

1. Text (Texto simples)

<input type="text" name="nome">

2. Password (Senha)

<input type="password" name="senha">

3. Email

<input type="email" name="email">

4. Tel (Telefone)

<input type="tel" name="telefone">

Tipos de Input - Números e Datas

1. Number (Número)

<input type="number" name="idade" min="0" max="120">

2. Date (Data)

<input type="date" name="nascimento">

3. Time (Hora)

<input type="time" name="horario">

4. Range (Intervalo)

<input type="range" name="volume" min="0" max="100">

Tipos de Input - Seleção

1. Checkbox (Caixa de Seleção)

Permite múltiplas seleções

<input type="checkbox" name="interesses" value="esportes" id="esportes">
<label for="esportes">Esportes</label>

<input type="checkbox" name="interesses" value="musica" id="musica">
<label for="musica">Música</label>


2. Radio (Botão de Opção)

Permite apenas uma seleção por grupo

<input type="radio" name="genero" value="M" id="masc">
<label for="masc">Masculino</label>

<input type="radio" name="genero" value="F" id="fem">
<label for="fem">Feminino</label>


Outros Tipos de Input Úteis

1. Color (Cor)

<input type="color" name="cor">

2. File (Arquivo)

<input type="file" name="arquivo">

3. URL

<input type="url" name="site">

4. Search (Busca)

<input type="search" name="buscar">

Select e Textarea

1. Select (Lista de Seleção)

<select name="estado" id="estado">
  <option value="">Selecione um estado</option>
  <option value="SP">São Paulo</option>
  <option value="RJ">Rio de Janeiro</option>
  <option value="MG">Minas Gerais</option>
</select>

2. Textarea (Área de Texto)

<textarea name="mensagem" id="mensagem" rows="5" cols="40">
  Digite sua mensagem aqui...
</textarea>

A Importância das Labels

Labels (rótulos) são fundamentais para a acessibilidade e usabilidade dos formulários.

Duas formas de usar:

1. Com atributo 'for':

<label for="nome">Nome Completo:</label>
<input type="text" id="nome" name="nome">

2. Envolvendo o input:

<label>
  Nome Completo:
  <input type="text" name="nome">
</label>
Benefícios das Labels:
• Melhora a acessibilidade para leitores de tela
• Aumenta a área clicável (clicar no texto ativa o campo)
• Melhora a experiência do usuário
• É uma boa prática de desenvolvimento

Organizando com Fieldset e Legend

Agrupe campos relacionados para melhor organização visual e semântica.

<fieldset>
  <legend>Dados Pessoais</legend>
  
  <label for="nome">Nome:</label>
  <input type="text" id="nome" name="nome"><br><br>
  
  <label for="email">Email:</label>
  <input type="email" id="email" name="email">
</fieldset>
Dados Pessoais



Quando usar Fieldset:
• Agrupar informações pessoais
• Separar endereço de entrega e cobrança
• Organizar opções de pagamento
• Agrupar preferências do usuário

Botões em Formulários

Três formas de criar botões:

1. Input type="submit" (Enviar)

<input type="submit" value="Enviar Formulário">

2. Input type="reset" (Limpar)

<input type="reset" value="Limpar Campos">

3. Tag Button (Mais flexível)

<button type="submit">Enviar</button>
<button type="reset">Limpar</button>
<button type="button">Ação Personalizada</button>

Validação HTML5

HTML5 oferece validação nativa sem necessidade de JavaScript:

Principais Atributos de Validação:

required

<input type="text" required>

Campo obrigatório

minlength / maxlength

<input type="text" minlength="3" maxlength="50">

Limite de caracteres

min / max

<input type="number" min="18" max="100">

Valores mínimo e máximo

pattern

<input type="text" pattern="[0-9]{3}-[0-9]{3}">

Expressão regular

Nota: A validação HTML5 é executada automaticamente quando o formulário é enviado, mas pode ser complementada com JavaScript para melhor controle.

Exemplo Completo - Formulário de Cadastro

<form action="cadastrar.php" method="POST">
  <fieldset>
    <legend>Cadastro de Usuário</legend>

    <label for="nome">Nome Completo:*</label>
    <input type="text" id="nome" name="nome" required><br><br>

    <label for="email">Email:*</label>
    <input type="email" id="email" name="email" required><br><br>

    <label for="senha">Senha:*</label>
    <input type="password" id="senha" name="senha" minlength="6" required><br><br>

    <label for="nascimento">Data de Nascimento:</label>
    <input type="date" id="nascimento" name="nascimento"><br><br>

    <label>Gênero:</label>
    <input type="radio" name="genero" value="M" id="masc">
    <label for="masc">Masculino</label>
    <input type="radio" name="genero" value="F" id="fem">
    <label for="fem">Feminino</label><br><br>

    <input type="checkbox" id="termos" required>
    <label for="termos">Aceito os termos de uso*</label><br><br>

    <button type="submit">Cadastrar</button>
    <button type="reset">Limpar</button>
  </fieldset>
</form>

Boas Práticas para Formulários

✅ Sempre faça:

  • Use labels para todos os campos
  • Marque campos obrigatórios com asterisco (*)
  • Use o tipo de input apropriado (email, tel, number, etc.)
  • Agrupe campos relacionados com fieldset
  • Forneça placeholders úteis
  • Use validação HTML5 nativa
  • Teste a acessibilidade do formulário

❌ Evite:

  • Formulários muito longos sem divisão
  • Campos sem labels ou identificação clara
  • Não indicar campos obrigatórios
  • Usar apenas placeholders como labels
  • Ignorar a ordem lógica dos campos
  • Não testar em diferentes navegadores
Dica: Sempre pense na experiência do usuário. Um formulário bem estruturado aumenta significativamente as taxas de conversão e satisfação.

Acessibilidade em Formulários

🔍 Por que é importante?

Formulários acessíveis garantem que TODOS os usuários possam interagir com seu site, incluindo pessoas com deficiências visuais, motoras ou cognitivas.

Principais Técnicas:

1. Use Labels Corretamente
Sempre associe labels aos campos usando o atributo 'for'
2. Ordem de Tabulação
Garanta que a navegação por TAB siga uma ordem lógica
3. Mensagens de Erro Claras
Forneça feedback específico sobre o que precisa ser corrigido
4. Contraste e Tamanho
Garanta que textos e campos tenham contraste adequado e tamanho legível
Teste com leitores de tela: Use ferramentas como NVDA ou JAWS para verificar se seu formulário é navegável sem mouse.

Exercício Prático 1

Crie um Formulário de Login

Implemente um formulário de login com os seguintes requisitos:

  • Campo de email (obrigatório)
  • Campo de senha (obrigatório, mínimo 8 caracteres)
  • Checkbox "Lembrar-me"
  • Link "Esqueceu a senha?"
  • Botão de enviar

Exercício Prático 2

Crie um Formulário de Pesquisa

Crie um formulário de pesquisa de satisfação com:

  • Campo de nome (opcional)
  • Seleção de idade (select com faixas etárias)
  • Avaliação do serviço (radio buttons de 1 a 5)
  • Checkboxes para melhorias desejadas
  • Campo de comentários (textarea)

Dicas Extras e Recursos

Dicas:

Atributo autocomplete

<input type="email" autocomplete="email">
<input type="tel" autocomplete="tel">

Ajuda o navegador a preencher campos automaticamente

Atributo autofocus

<input type="text" autofocus>

Define o foco inicial no campo quando a página carrega
