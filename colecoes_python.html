Introdução às Coleções em Python

Bem-vindos à aula sobre coleções em Python! Hoje vamos aprender sobre estruturas de dados fundamentais para organizar e manipular informações.

O que são coleções?

Coleções são estruturas de dados que nos permitem armazenar múltiplos valores em uma única variável.

Imagine uma caixa onde você pode guardar vários itens - é isso que uma coleção faz no Python!

Por que usar coleções? Elas nos ajudam a organizar dados, facilitam operações repetitivas e tornam nosso código mais eficiente.

Tipos de Coleções que veremos hoje:

  • Listas
  • Tuplas
  • Dicionários
  • Conjuntos

Listas em Python

Listas são coleções ordenadas e mutáveis (podemos alterar seus elementos após a criação).

# Criando uma lista
frutas = ["maçã", "banana", "laranja", "uva"]
numeros = [1, 2, 3, 4, 5]
misturado = [10, "texto", True, 3.14]

Características das Listas:

  • São ordenadas (mantêm a ordem dos elementos)
  • Podem conter itens de tipos diferentes
  • Podem ser alteradas após a criação (mutáveis)
  • Permitem itens duplicados
# Acessando elementos (o primeiro item tem índice 0)
print(frutas[0]) # maçã
print(frutas[2]) # laranja

# Alterando um elemento
frutas[1] = "morango"
print(frutas) # ["maçã", "morango", "laranja", "uva"]

Operações com Listas

# Adicionando elementos
frutas.append("abacaxi") # Adiciona no final
frutas.insert(1, "kiwi") # Insere na posição 1

# Removendo elementos
frutas.remove("laranja") # Remove pelo valor
frutas.pop(2) # Remove pelo índice

# Tamanho da lista
print(len(frutas)) # Mostra quantos itens tem

# Verificando existência
if "banana" in frutas:
    print("Tem banana!")
#Percorrendo uma lista
for f in frutas:
print(f)

Tuplas em Python

Tuplas são semelhantes às listas, mas são imutáveis (não podem ser alteradas após a criação).

# Criando uma tupla
coordenadas = (10, 20)
cores = ("vermelho", "verde", "azul")
misturado = (1, "texto", True)

# Acessando elementos
print(cores[1]) # verde

# Tentativa de alteração (gera erro)
# cores[1] = "amarelo" # TypeError

Quando usar tuplas?

  • Quando os dados não devem ser alterados
  • Para garantir que os dados permaneçam consistentes
  • Quando precisamos de coleções mais eficientes (tuplas são mais rápidas que listas)

Curiosidade: Tuplas com um único elemento precisam de uma vírgula no final: tupla = (1,)

Dicionários em Python

Dicionários armazenam pares de chave-valor e são muito úteis para dados organizados.

# Criando um dicionário
aluno = {
    "nome": "João Silva",
    "idade": 16,
    "turma": "2ºA",
    "notas": [7.5, 8.0, 6.5]
}

# Acessando valores
print(aluno["nome"]) # João Silva
print(aluno.get("idade")) # 16

# Adicionando/alterando valores
aluno["escola"] = "Escola Técnica"
aluno["idade"] = 17

Características dos Dicionários:

  • Não ordenados (antes do Python 3.7)
  • Mutáveis (podemos alterar, adicionar ou remover itens)
  • Não permitem chaves duplicadas
  • Chaves devem ser imutáveis (strings, números ou tuplas)

Operações com Dicionários

# Removendo itens
aluno.pop("turma") # Remove pelo nome da chave
del aluno["idade"] # Outra forma de remover

# Verificando existência de chave
if "notas" in aluno:
    print("Tem informações de notas")

# Percorrendo o dicionário
for chave, valor in aluno.items():
    print(f"{chave}: {valor}")

# Listando todas as chaves
print(aluno.keys())

# Listando todos os valores
print(aluno.values())

Conjuntos em Python

Conjuntos (sets) são coleções não ordenadas de itens únicos (não permitem duplicatas).

# Criando um conjunto
numeros = {1, 2, 3, 4, 5}
letras = set(["a", "b", "c", "a"]) # {'a', 'b', 'c'}

# Adicionando elementos
numeros.add(6)
numeros.update([7, 8, 9])

# Removendo elementos
numeros.remove(3) # Gera erro se o elemento não existir
numeros.discard(10) # Não gera erro

# Operações matemáticas
a = {1, 2, 3}
b = {3, 4, 5}
print(a.union(b)) # {1, 2, 3, 4, 5}
print(a.intersection(b)) # {3}

Quando usar conjuntos?

  • Para remover duplicatas de uma lista
  • Para testar pertinência de forma eficiente
  • Para operações matemáticas de conjuntos (união, interseção, etc.)

Comparando as Coleções

Listas

  • Ordenadas
  • Mutáveis
  • Permite duplicatas
  • Sintaxe: [ ]
  • Uso: Quando a ordem e a mutabilidade são importantes

Tuplas

  • Ordenadas
  • Imutáveis
  • Permite duplicatas
  • Sintaxe: ( )
  • Uso: Quando os dados não devem mudar

Dicionários

  • Não ordenados (antes do Python 3.7)
  • Mutáveis
  • Chaves únicas
  • Sintaxe: { }
  • Uso: Para dados nomeados/identificados

Conjuntos

  • Não ordenados
  • Mutáveis
  • Elementos únicos
  • Sintaxe: { }
  • Uso: Para operações matemáticas ou eliminar duplicatas

Resumo e Conclusão

O que aprendemos hoje?

  • Listas: coleções ordenadas e mutáveis [ ]
  • Tuplas: coleções ordenadas e imutáveis ( )
  • Dicionários: pares chave-valor { }
  • Conjuntos: coleções de itens únicos { }

Dica: Escolha a coleção certa para cada situação:

  • Precisa de ordem e poder mudar? → Lista
  • Dados fixos que não mudam? → Tupla
  • Dados com identificadores? → Dicionário
  • Precisa garantir unicidade? → Conjunto
