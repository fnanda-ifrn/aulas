O que são Pacotes em Python?

Pacotes são uma forma de organizar módulos Python em diretórios.

Exemplo de estrutura:

meu_pacote/
├── __init__.py
├── modulo1.py
└── modulo2.py

Pacotes ajudam a:

  • Organizar melhor o código
  • Evitar conflitos de nomes
  • Facilitar a distribuição do código
3/10

O Arquivo __init__.py

O __init__.py é um arquivo especial que transforma um diretório comum em um pacote Python.

Observação: Nas versões mais recentes do Python (3.3+), o __init__.py não é mais obrigatório, mas ainda é muito usado.

Ele pode estar vazio ou conter código de inicialização do pacote.

Exemplo mínimo:

# __init__.py vazio
# Apenas marca o diretório como um pacote Python
4/10

O que podemos colocar no __init__.py?

O __init__.py pode conter:

  • Código de inicialização do pacote
  • Definição de variáveis e funções
  • Importações que ficam disponíveis quando o pacote é importado
  • Documentação do pacote (docstring)
  • A lista __all__ para controlar importações

Exemplo com conteúdo:

"""
Este é o pacote de matemática da nossa escola.
Ele contém funções úteis para cálculos.
"""

# Definindo uma constante
PI = 3.14159

# Importando funções para ficarem disponíveis diretamente no pacote
from .operacoes import soma, subtracao

Exemplo Prático - Criando um Pacote

Estrutura do projeto:

matematica/
├── __init__.py
└── operacoes.py

operacoes.py:

def soma(a, b):
    return a + b

def subtracao(a, b):
    return a - b

def _divisao(a, b):  # Função "privada" (por convenção)
    return a / b

__init__.py:

from .operacoes import soma, subtracao

__all__ = ['soma', 'subtracao']

Usando o pacote:

import matematica

resultado = matematica.soma(5, 3)
print(resultado)  # Saída: 8

Controlando Importações com __all__

O __all__ é uma lista especial no __init__.py que define quais partes do pacote ficam disponíveis quando usamos:

from pacote import *

Exemplo no __init__.py:

# Define quais funções serão exportadas com 'import *'
__all__ = ['soma', 'subtracao']

# Importa as funções do módulo operacoes
from .operacoes import soma, subtracao, _divisao

Resultado:

from matematica import *

soma(2, 3)      # Funciona (está em __all__)
subtracao(5, 2) # Funciona (está em __all__)
_divisao(6, 3)  # ERRO! (não está em __all__)

Dica profissional: Mesmo com __all__, é melhor evitar import * e importar somente o que for usar!

Pacotes Python Populares

Python tem uma grande coleção de pacotes úteis. Vamos conhecer alguns:

  • math - Funções matemáticas
  • random - Geração de números aleatórios
  • datetime - Trabalhar com datas e horas
  • os - Interação com o sistema operacional
  • requests - Fazer requisições HTTP
8/10

Exemplos com Pacotes Populares

math - Matemática:

import math

print(math.sqrt(16))  # 4.0
print(math.pi)        # 3.141592653589793

random - Aleatoriedade:

import random

print(random.randint(1, 10))  # Número entre 1 e 10
print(random.choice(['cara', 'coroa']))  # Escolhe aleatoriamente
9/10

Mais Exemplos com Pacotes Populares

datetime - Datas e Horas:

from datetime import datetime, timedelta

hoje = datetime.now()
print(hoje)  # 2023-11-15 14:30:00.123456

amanha = hoje + timedelta(days=1)
print(amanha)  # 2023-11-16 14:30:00.123456

os - Sistema Operacional:

import os

print(os.getcwd())  # Mostra o diretório atual
print(os.listdir())  # Lista arquivos no diretório
