Criando sua Primeira Interface

  • Criar novo arquivo: File → New → Main Window
  • Adicionar widgets: Arraste QPushButton, QLabel e QLineEdit
  • Configurar propriedades:
    • objectName: btnEnviar
    • text: "Enviar"
    • Ajuste fontes e tamanhos
  • Salvar: File → Save As → minha_interface.ui
💡 Dica Importante Sempre use nomes descritivos em objectName! Use btnSalvar ao invés de pushButton_1

Conectando ao Código Python

Método 1: Converter .ui para .py

pyuic5 minha_interface.ui -o minha_interface.py

Método 2: Carregar .ui diretamente (Mais simples)

from PyQt5 import uic
from PyQt5.QtWidgets import QApplication

app = QApplication([])
janela = uic.loadUi("minha_interface.ui")
janela.show()
app.exec_()
