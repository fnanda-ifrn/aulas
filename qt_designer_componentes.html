Qt Designer

Propriedades, Métodos e Sinais

O Qt Designer é uma ferramenta visual para criar interfaces de usuário com o framework Qt. Ele permite criar janelas e diálogos usando uma interface de arrastar e soltar.

Objetivos:

  • Principais componentes do Qt Designer
  • Propriedades que controlam aparência e comportamento
  • Métodos para interagir com os componentes
  • Sinais para responder a eventos do usuário

Cada componente Qt possui três aspectos principais:

  • Propriedades: Atributos que definem aparência e comportamento
  • Métodos: Funções que podemos chamar para interagir com o componente
  • Sinais: Eventos emitidos quando algo acontece com o componente

QLabel

Exibição de texto e imagens

O QLabel é usado para exibir texto ou imagens que não podem ser editados pelo usuário.

Propriedades Principais

text - Texto exibido
pixmap - Imagem exibida
alignment - Alinhamento do texto
wordWrap - Quebra automática de linha

Métodos Principais

setText() - Define o texto
text() - Retorna o texto atual
setPixmap() - Define uma imagem
clear() - Limpa o conteúdo

Sinais

linkActivated() - Link clicado
linkHovered() - Mouse sobre link

Exemplo de uso:

# Criando um QLabel
label = QLabel("Texto do Label")
label.setAlignment(Qt.AlignCenter)
label.setStyleSheet("color: blue; font-size: 16px;")

Botões

Componentes para interação do usuário através de cliques.

QPushButton

Propriedades:

text - Texto do botão
icon - Ícone do botão

checked - Estado marcado

Sinais:

clicked() - Botão clicado
toggled() - Estado mudou

QRadioButton

Propriedades:

text - Texto do botão
checked - Estado marcado

Sinais:

toggled() - Estado mudou

QCheckBox

Propriedades:

text - Texto da caixa
checked - Estado marcado
tristate - Permite terceiro estado
checkState - Estado completo

Sinais:

stateChanged() - Estado mudou

Conectando sinais a funções:

# Conectando um botão a uma função
button.clicked.connect(self.minha_funcao)

# Conectando um checkbox
checkbox.stateChanged.connect(self.estado_mudou)

Componentes para entrada e seleção de valores numéricos.

QSpinBox (Inteiros)

Propriedades:

value - Valor atual

maximum - Valor máximo

Sinais:

QDoubleSpinBox (Decimais)

Propriedades:

value - Valor atual

Sinais:

QSlider

Propriedades:

value - Valor atual
orientation - Orientação
tickPosition - Posição das marcas

Sinais:

valueChanged()
sliderMoved()

Exemplo de uso:

# Criando um spinbox para idade
idade_spinbox = QSpinBox()
idade_spinbox.setRange(0, 120)
idade_spinbox.setValue(25)
idade_spinbox.setSuffix(" anos")
idade_spinbox.valueChanged.connect(self.idade_mudou)

Propriedades Comuns

Herdadas de QWidget

Todos os componentes Qt herdam propriedades e métodos da classe base QWidget.

Propriedades Visuais

enabled - Habilitado/Desabilitado
visible - Visível/Oculto
geometry - Posição e tamanho
styleSheet - Estilo CSS
font - Fonte do texto
toolTip - Dica de ferramenta

Métodos de Controle

show() - Mostra o widget
hide() - Oculta o widget
setEnabled() - Habilita/Desabilita
setGeometry() - Define posição/tamanho
setStyleSheet() - Define estilo
setFocus() - Define foco

Exemplo de estilização com CSS:

# Aplicando estilo a um botão
botao.setStyleSheet("""
    QPushButton {
        background-color: #4CAF50;
        color: white;
        border: none;
        padding: 10px;
        border-radius: 5px;
    }
    QPushButton:hover {
        background-color: #45a049;
    }
""")

Sinais e Slots

Comunicação entre componentes

O sistema de Sinais e Slots é um mecanismo de comunicação entre objetos Qt, permitindo que um objeto emita um sinal quando ocorre um evento, e outros objetos possam conectar-se a esse sinal através de slots (funções).

Conectando Sinais a Slots

objeto.sinal.connect(funcao)

Exemplos:

  • botao.clicked.connect(self.minha_funcao)
  • spinbox.valueChanged.connect(self.valor_mudou)
  • lineedit.textChanged.connect(self.texto_mudou)

Sinais com Parâmetros

Muitos sinais enviam parâmetros para as funções conectadas:

  • textChanged(QString texto)
  • valueChanged(int valor)
  • currentIndexChanged(int indice)

Exemplo completo:

class MinhaJanela(QMainWindow):
    def __init__(self):
        super().__init__()
        
        # Criando componentes
        self.botao = QPushButton("Clique aqui")
        self.label = QLabel("Texto inicial")
        
        # Conectando sinal a slot
        self.botao.clicked.connect(self.botao_clicado)
        
    def botao_clicado(self):
        self.label.setText("Botão foi clicado!")
