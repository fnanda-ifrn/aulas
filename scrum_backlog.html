O que é Scrum?

Framework ágil para gerenciar projetos complexos, com foco em:

  • Entregas incrementais de valor (Sprints)
  • Adaptação contínua a mudanças
  • Colaboração entre times multidisciplinares

Princípios-chave:

Transparência Inspeção Adaptação
Artefatos visíveis Revisões frequentes Ajustes contínuos

Hierarquia do Backlog

Como organizar os itens do maior para o menor

Estrutura típica:

  1. Épico: Grande área de funcionalidade (ex: Autenticação)
  2. Feature: Funcionalidade específica (ex: Login com e-mail)
  3. User Story: Requisito do usuário (formato: "Como [usuário], quero [ação] para [benefício]")
  4. Tarefas: Itens técnicos para implementar a User Story

Como bibliotecário, quero cadastrar novos livros com ISBN, título e autor

Épico: Cadastro | Pontos: 8

Critérios de Aceitação

  1. ISBN válido (13 dígitos)
  2. Título obrigatório (min 3 caracteres)
  3. Upload de capa (opcional, JPG/PNG, 2MB)
  4. Feedback claro de sucesso/erro
