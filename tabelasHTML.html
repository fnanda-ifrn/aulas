Por Que Usamos Tabelas em HTML?

Tabelas são usadas para organizar and exibir dados tabulares, ou seja, informações que naturalmente se encaixam em linhas e colunas.

  • Horários de aulas
  • Resultados esportivos
  • Listas de produtos
  • Informações financeiras

Importante: Não use tabelas para o layout visual da página! Use-as apenas para dados tabulares.

Elementos Básicos de uma Tabela

  • <table>: O contêiner principal da tabela.
  • <tr> (Table Row): Define uma linha na tabela.
  • <th> (Table Header): Define uma célula de cabeçalho. (Texto em negrito e centralizado por padrão)
  • <td> (Table Data): Define uma célula de dados comum.

Cada elemento tem uma função específica na construção da tabela.

Exemplo 1: Nossa Primeira Tabela Simples

código.html HTML 

<!DOCTYPE html>
<html lang="pt-br">
<head>
    <meta charset="UTF-8">
    <title>Minha Primeira Tabela</title>
</head>
<body>

    <h1>Lista de Alunos</h1>

    <table>
        <!-- Primeira linha: cabeçalhos -->
        <tr>
            <th>Nome</th>
            <th>Idade</th>
        </tr>
        <!-- Segunda linha: dados do aluno 1 -->
        <tr>
            <td>Ana Silva</td>
            <td>16</td>
        </tr>
        <!-- Terceira linha: dados do aluno 2 -->
        <tr>
            <td>Bruno Costa</td>
            <td>17</td>
        </tr>
    </table>

</body>
</html>

A Magia das Tags Semânticas

Melhoram a acessibilidade, a organização do código e facilitam a estilização futura.

  • <thead>: Agrupa o cabeçalho da tabela (linhas com <th>).
  • <tbody>: Agrupa o corpo da tabela (linhas com <td>). Pode haver múltiplos.
  • <tfoot>: Agrupa o rodapé da tabela (resumos, totais).

Essas tags não alteram a aparência visual, mas dão significado estrutural aos dados.

Exemplo 2: Tabela com Estrutura Semântica

tabela-semantica.html HTML 

<table>
    <!-- Cabeçalho da tabela -->
    <thead>
        <tr>
            <th>Disciplina</th>
            <th>Nota 1º Bimestre</th>
            <th>Nota 2º Bimestre</th>
        </tr>
    </thead>
    
    <!-- Corpo da tabela -->
    <tbody>
        <tr>
            <td>Matemática</td>
            <td>8.5</td>
            <td>9.0</td>
        </tr>
        <tr>
            <td>Português</td>
            <td>7.0</td>
            <td>7.5</td>
        </tr>
    </tbody>
    
    <!-- Rodapé da tabela -->
    <tfoot>
        <tr>
            <td colspan="3">Médias calculadas com base nas notas.</td>
        </tr>
    </tfoot>
</table>

Atributos Importantes: colspan e rowspan

Permitem que uma célula ocupe o espaço de várias colunas ou linhas, respectivamente.

  • colspan="N": A célula se estende por N colunas.
  • rowspan="N": A célula se estende por N linhas.

Dica: Ao usar, lembre-se de ajustar o número total de células na linha/coluna!

Exemplo de código 

<td colspan="2">Ocupa duas colunas</td>
<td rowspan="3">Ocupa três linhas</td>

Exemplo 3: Tabela com colspan e rowspan

tabela-avancada.html HTML 

<table>
    <thead>
        <tr>
            <th colspan="2">Contato</th>
            <th rowspan="2">Email</th>
        </tr>
        <tr>
            <th>Nome</th>
            <th>Telefone</th>
        </tr>
    </thead>
    <tbody>
        <tr>
            <td>Carlos Pereira</td>
            <td>(11) 9876-5432</td>
            <td>carlos.p@email.com</td>
        </tr>
        <tr>
            <td colspan="3">Agenda atualizada em Setembro de 2025.</td>
        </tr>
    </tbody>
</table>

Resumo da Aula

  • Estrutura Básica: <table>, <tr>, <th>, <td>.
  • Tags Semânticas: <thead>, <tbody>, <tfoot> para organização.
  • Atributos Avançados: colspan e rowspan para flexibilidade no layout das células.

O objetivo principal das tabelas is organizar dados de forma clara e acessível.
