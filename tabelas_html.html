Tabelas em HTML

Introdução

As tabelas são elementos fundamentais para organizar e exibir dados de forma estruturada em páginas web.

Nesta apresentação, você aprenderá:

  • A estrutura básica de uma tabela HTML
  • Elementos essenciais para criar tabelas
  • Atributos úteis para tabelas
  • Como estilizar tabelas com CSS
  • Boas práticas de acessibilidade

Tabelas em HTML

Estrutura Básica

Código HTML:

<table border="1">
    <tr>
        <th>Cabeçalho 1</th>
        <th>Cabeçalho 2</th>
    </tr>
    <tr>
        <td>Dado 1</td>
        <td>Dado 2</td>
    </tr>
</table>

Resultado sem CSS:

Cabeçalho 1 Cabeçalho 2
Dado 1 Dado 2

Resultado com CSS:

Cabeçalho 1 Cabeçalho 2
Dado 1 Dado 2

Exemplo Renderizado

Código HTML:

<table>
    <tr>
        <th>Nome</th>
        <th>Idade</th>
        <th>Cidade</th>
    </tr>
    <tr>
        <td>João</td>
        <td>25</td>
        <td>São Paulo</td>
    </tr>
    <tr>
        <td>Maria</td>
        <td>30</td>
        <td>Rio de Janeiro</td>
    </tr>
</table>

Resultado sem CSS:

Nome Idade Cidade
João 25 São Paulo
Maria 30 Rio de Janeiro

Resultado com CSS:

Nome Idade Cidade
João 25 São Paulo
Maria 30 Rio de Janeiro

Observe que:

  • As células <th> são exibidas em negrito por padrão
  • Cada linha é definida por <tr>
  • Cada célula de dados é definida por <td>

Tabelas em HTML

Atributos Úteis

Alguns atributos importantes para tabelas:

Código HTML:

<table border="1">
    <tr>
        <th>Atributo</th>
        <th>Descrição</th>
        <th>Exemplo</th>
    </tr>
    <tr>
        <td>border</td>
        <td>Define a borda da tabela</td>
        <td><table border="1"></td>
    </tr>
    <tr>
        <td>colspan</td>
        <td>Faz uma célula ocupar várias colunas</td>
        <td><td colspan="2"></td>
    </tr>
    <tr>
        <td>rowspan</td>
        <td>Faz uma célula ocupar várias linhas</td>
        <td><td rowspan="3"></td>
    </tr>
</table>

Resultado sem CSS:

Atributo Descrição Exemplo
border Define a borda da tabela <table border="1">
colspan Faz uma célula ocupar várias colunas <td colspan="2">
rowspan Faz uma célula ocupar várias linhas <td rowspan="3">

Resultado com CSS:

Atributo Descrição Exemplo
border Define a borda da tabela <table border="1">
colspan Faz uma célula ocupar várias colunas <td colspan="2">
rowspan Faz uma célula ocupar várias linhas <td rowspan="3">

Tabelas em HTML

colspan e rowspan

Código HTML:

<table border="1">
    <tr>
        <th colspan="2">Nome Completo</th>
        <th rowspan="2">Idade</th>
    </tr>
    <tr>
        <th>Primeiro Nome</th>
        <th>Sobrenome</th>
    </tr>
    <tr>
        <td>João</td>
        <td>Silva</td>
        <td>25</td>
    </tr>
</table>

Resultado sem CSS:

Nome Completo Idade
Primeiro Nome Sobrenome
João Silva 25

Resultado com CSS:

Nome Completo Idade
Primeiro Nome Sobrenome
João Silva 25

Tabelas em HTML

Elementos Semânticos

Código HTML:

<table border="1">
    <caption>Lista de Funcionários</caption>
    <thead>
        <tr>
            <th>Nome</th>
            <th>Cargo</th>
            <th>Salário</th>
        </tr>
    </thead>
    <tbody>
        <tr>
            <td>Ana</td>
            <td>Desenvolvedora</td>
            <td>R$ 5.000</td>
        </tr>
        <tr>
            <td>Carlos</td>
            <td>Designer</td>
            <td>R$ 4.500</td>
        </tr>
    </tbody>
    <tfoot>
        <tr>
            <td colspan="2">Total</td>
            <td>R$ 9.500</td>
        </tr>
    </tfoot>
</table>

Resultado sem CSS:

Lista de Funcionários
Nome Cargo Salário
Ana Desenvolvedora R$ 5.000
Carlos Designer R$ 4.500
Total R$ 9.500

Resultado com CSS:

Lista de Funcionários
Nome Cargo Salário
Ana Desenvolvedora R$ 5.000
Carlos Designer R$ 4.500
Total R$ 9.500

Exercício

Crie uma tabela HTML que represente o horário de aulas de uma escola com as seguintes características:

  1. Colunas: Dias da semana (Segunda a Sexta)
  2. Linhas: Horários (8:00, 10:00, 14:00, 16:00)
  3. Use <thead> e <tbody>
  4. Adicione um <caption> com "Horário Escolar"
  5. Use colspan para criar um cabeçalho "Horário" que ocupe duas colunas
  6. Adicione pelo menos uma célula vazia para horário sem aula
  7. Use os atributos scope apropriados
